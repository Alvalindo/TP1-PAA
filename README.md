# TP1-PAA
Imagine um labirinto cheio de salas interligadas, cada uma contendo uma chave ou não. Um aventureiro começa em uma sala inicial e deve encontrar um caminho para a sala de um baú misterioso com tesouros, mas que requer um número específico de chaves para abri-lo

## Compilação e execução

Com GNU Make e GCC instalados, use:

```sh
make
make run
```

O executável será criado em `bin/labirinto`. Para remover o executável e os arquivos objeto:

```sh
make clean
```
